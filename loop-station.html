Loop Station

This HTML file includes all the required features and functionality as per your specifications. The audio context, gain, compressor, and destination are set up in the `initAudio` function. The `loadFile` function handles the file input event and decodes the audio data using `decodeAudioData`. The `initPlayback` function initializes the playback by connecting the master gain to the destination and setting up the play button, stop button, and loop label events. The waveform is drawn on the canvas in the `drawWaveform` function, which uses the device pixel ratio for crisp rendering. The animate function uses requestAnimationFrame to draw the waveform continuously. The playLoop function starts playback from the current start marker to end marker, and the stopPlayback function stops playback by disconnecting the current source. The toggleLoop function toggles loop mode on or off, and the resizeCanvas function resizes the canvas when the window is resized.
