# SPEC.md — Filter Lab

## Concept & Vision
Browser-based parametric EQ with a live frequency response visualizer. Load or generate a test tone, apply low-pass/high-pass/band-pass filters, see the real-time frequency response curve drawn on canvas. Master chain includes DynamicsCompressor for speaker protection.

## Parameters to Test
- **Temperature:** 0.75
- **Token limit:** 2000
- **Goal:** Test updated structural vs patchable split — createBiquadFilter and createAnalyser are structural, should trigger model retry if missing

## Design Language
- Dark background `#0a0a0f`, neon cyan `#00f5d4`, neon magenta `#f72585`
- Space Mono (headings) + Inter (body) from Google Fonts
- Single self-contained HTML file

## Features
1. **Filter type selector** — Low-pass, High-pass, Band-pass buttons; creates new BiquadFilterNode on selection
2. **Frequency control** — range slider 20–20000Hz (log scale), displays current Hz; uses `filter.frequency.setTargetAtTime()`
3. **Q/Resonance control** — range slider 0.1–20, displays current Q value; uses `filter.Q.setTargetAtTime()`
4. **Frequency response canvas** — draws the EQ curve using `getFrequencyResponse()`; uses `devicePixelRatio` for crisp rendering; animated with `requestAnimationFrame`
5. **Test tone** — Play/Stop button generates a noise burst through the filter chain
6. **Master chain:** OscillatorNode/BufferSource → BiquadFilter → GainNode → DynamicsCompressor → AnalyserNode → destination
7. All param changes use `setTargetAtTime` (not direct `.value` assignment)

## Code Requirements
- Required functions: `initAudio`, `setFilterFreq`, `setFilterQ`, `drawResponse`, `playTest`, `stopTest`
- `createBiquadFilter` MUST be generated by model (structural)
- `createAnalyser` MUST be generated by model (structural)
- Canvas uses `devicePixelRatio`
- Animation uses `requestAnimationFrame` in `drawResponse`
- Master chain includes `DynamicsCompressor`
- All AudioParam changes use `setTargetAtTime`

## Layout
- Top: `<h1>Filter Lab</h1>`
- Middle: frequency response canvas (full width, ~200px tall)
- Bottom: filter type buttons [LP] [HP] [BP] + frequency slider + Q slider + [▶ Play] [■ Stop]
- Responsive: canvas resizes with window
